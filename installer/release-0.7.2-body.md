## 修复

### 专业课在今日计划页被错误显示为数学卷种

考试类型使用简称（如「数二 / 英二 / 政治 / 专业课」）时，今日计划页的科目名称解析只认「数学」「英语」这类全称，匹配失败后把考试类型里剩下的第一项（也就是数学卷种名）当成了专业课的名称，于是专业课分组标题错误显示成了数学卷种。

现在科目名称解析同时兼容简称与全称（数二 / 数学二 均可识别），专业课只在明确写了具体统考科目名（如「408 计算机」「法律硕士」）时使用该名称，否则显示为「专业课」；首次引导回填时也不会再把泛称「专业课」记成自定义专业课名。

### 设置页移除两项已失效的功能分配

「功能 Provider 分配」中的「每日简报」（简报不再生成今日寄语）与「解惑答疑」（解惑页已下线）已无实际用途，现已移除，保留「进度表 / 考纲生成」「周计划与目标倒排」「复盘分析」三项。旧配置中若已为这两项指定过 Provider，设置数据不会被清除，仍按原样生效。

### 引导与说明文案与实际功能对齐

首次引导「考试科目」步骤的示例改用与实际选项一致的简称（数二 / 英一），「配置 AI 助手」步骤移除已无对应入口的「教学讲解」描述，避免说明与界面选项、实际功能不一致。

## 优化

### 设置页 Provider 配置合并为一张卡片

「AI Provider」与「功能 Provider 分配」原本是两张独立卡片，现在合并为同一张卡片（功能分配位于 Provider 列表下方，用分隔线区分），减少设置页的卡片数量。
